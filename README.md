# 智慧校园 · 管理平台原型（Campus OS）

> 一个**纯静态、零依赖**的大学校园管理平台高保真 UI 原型，用于演示「校园一体化后台」应该长什么样。所有图表用内联 SVG 绘制，无需任何构建工具或外部库，双击 `index.html` 即可在浏览器打开。
>
> ⚠️ 本仓库为 **UI / 交互原型**，不含后端逻辑，数据均为演示用静态数据（由各页面内 JS 生成）。

## 🌐 在线预览

**GitHub Pages：https://wadesha.github.io/campus-platform/**

## 它解决了什么

高校信息化常见「系统孤岛」：教务、宿舍、一卡通、财务、安防各自为政。本原型把分散业务**统一到一个入口**，让管理员在一块屏幕上完成「看数据 → 接待办 → 处预警」的闭环。

## ✨ 核心特性

- **数据总览看板**：6 个 KPI + 趋势/占比图表 + 实时待办/审批/预警，首屏即可决策
- **6 个可交互业务子页**：学生、教务、宿舍、一卡通、财务，均支持搜索 / 筛选 / 分页
- **详情抽屉**：列表任意行点击右侧滑出，多页签展示明细（如学生的考勤/消费/预警）
- **统一侧边导航**：6 页互相跳转，深色高密度风格，信息密度高、无松散留白
- **零依赖离线可用**：纯 HTML + CSS + 内联 SVG + 原生 JS，无框架、无打包、无 CDN

## 🧭 如何浏览

直接点左侧导航在页面间跳转：

| 页面 | 文件 | 说明 |
|------|------|------|
| 数据总览 | `index.html` | 全局看板（首屏），含 KPI / 趋势 / 待办 / 审批 / 预警 |
| 学生管理 | `students.html` | 64 条演示学生，搜索 / 院系·年级·状态筛选 / 分页 / 详情抽屉（基本信息·考勤·一卡通·预警） |
| 教务管理 | `academic.html` | 课程列表，学期 / 状态筛选 / 详情抽屉（课程信息·成绩分布·学生名单） |
| 宿舍管理 | `dorm.html` | 房间列表，楼栋 / 状态筛选 / 详情抽屉（床位·住宿生·水电报修） |
| 一卡通 / 消费 | `card.html` | 消费记录，场景 / 异常筛选 / 详情抽屉（交易记录·场景占比·异常核查） |
| 财务缴费 | `finance.html` | 缴费明细，费用类型 / 状态筛选 / 详情抽屉（项目拆分·缴费记录·催办） |

> 导航中其余模块（今日待办、资产设备、通知公告、安全预警、系统设置）为占位，后续按同模板扩展。

## 🛠 技术说明

- 纯静态：6 个独立 `*.html`，HTML + CSS + 内联 SVG
- 无框架、无打包、无 CDN：完全离线可用
- 深色主题，紧凑网格，高信息密度（契合后台管理场景）
- 演示数据由各页面内原生 JS 确定性生成，刷新结果稳定

## 💻 本地运行

```bash
# 方式一：直接打开
open index.html

# 方式二：本地静态服务（推荐，避免个别浏览器对本地文件的限制）
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```
