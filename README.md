# 智慧校园 · 管理平台原型（Campus OS）

一个**单文件、零依赖**的大学校园管理平台高保真 UI 原型，用于演示「校园一体化后台」应该长什么样。所有图表用内联 SVG 绘制，无需任何构建工具或外部库，双击 `index.html` 即可在浏览器打开。

> 本仓库为 **UI / 交互原型**，不含后端逻辑。数据均为演示用静态数据。

## 在线预览

🌐 GitHub Pages：**https://wadesha.github.io/campus-platform/**

## 这个平台解决了什么

高校信息化通常存在系统孤岛：教务、宿舍、一卡通、财务、安防各自为政。本原型把分散业务**统一到一个入口**，让管理员在一块屏幕上完成「看数据 → 接待办 → 处预警」的闭环。

## 功能模块

| 模块 | 说明 |
|------|------|
| 数据总览 | 全校核心指标看板（在校生、考勤、缴费、宿舍、预警） |
| 学生管理 | 学籍、档案、异动 |
| 教务管理 | 选课、排课、成绩 |
| 宿舍管理 | 楼栋、床位、调宿、用电 |
| 一卡通 / 消费 | 消费构成、异常核查 |
| 财务缴费 | 学费、教材费、欠缴催办 |
| 资产设备 | 实验室设备、报修 |
| 通知公告 | 全校发布与已读统计 |
| 安全预警 | 未归、异常消费、门禁——校园场景独有 |
| 系统设置 | 权限、SLA 监控 |

## 首屏布局

- **左侧分组导航**：主控制台 / 业务管理 / 协同
- **顶部全局搜索**：学号、姓名、工单号、设备
- **6 个 KPI 卡**：直接回答「今天该关心什么」
- **可视化优先**：趋势折线、占比环形/条形，表格只放「需要人处理」的工单与预警

## 技术说明

- 纯静态：单 `index.html`，HTML + CSS + 内联 SVG
- 无框架、无打包、无 CDN：完全离线可用
- 深色主题，紧凑网格，高信息密度

## 本地运行

```bash
# 方式一：直接打开
open index.html

# 方式二：本地静态服务（推荐，避免个别浏览器限制）
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

## 多页面结构（可点击导航）

侧边导航已在页面间打通，支持互跳：

| 页面 | 文件 | 说明 |
|------|------|------|
| 数据总览 | `index.html` | 全局看板（首屏），含 KPI / 趋势 / 待办 / 审批 / 预警 |
| 学生管理 | `students.html` | 64 条演示学生，搜索 / 院系·年级·状态筛选 / 分页 / 详情抽屉（基本信息·考勤·一卡通·预警） |
| 教务管理 | `academic.html` | 课程列表，学期 / 状态筛选 / 详情抽屉（课程信息·成绩分布·学生名单） |
| 宿舍管理 | `dorm.html` | 房间列表，楼栋 / 状态筛选 / 详情抽屉（床位·住宿生·水电报修） |
| 一卡通 / 消费 | `card.html` | 消费记录，场景 / 异常筛选 / 详情抽屉（交易记录·场景占比·异常核查） |
| 财务缴费 | `finance.html` | 缴费明细，费用类型 / 状态筛选 / 详情抽屉（项目拆分·缴费记录·催办） |

> 所有子页共用同一套侧边导航，可互相跳转。其余模块（今日待办、资产设备、通知公告、安全预警、系统设置）在导航中占位，后续按同模板扩展。
